# Where answers come from, and what I did

Two records are kept by the program itself, never written by the model, so
neither can be talked into saying something that did not happen.

## Sources under every answer
Each answer lists what it was built from: things I remember (with the file
or conversation they came from), files I read, web pages and search results.
Each has a number. In a written answer, a sentence that relies on a source
ends with that number, like [2]. A number that points nowhere is taken out
before you see the answer, so every number you see can be checked.

Open the list under an answer to see each source: what kind it is, its name,
a few words of what was taken from it, and whether the answer cites it or
only read it. A web address opens in your own browser; a file opens its
folder. Spoken answers are listed without numbers, because "[2]" read aloud
is noise. The list is kept with the conversation, so it is there when you
open it again next week.

Switch numbering off under Control → Answers. The list is still kept.

## What I did and why
Every action I take is recorded: reading a file, searching the web, writing
a document, sending a message — and also every action I put to you and every
one that was refused. Each entry says what was asked that led to it, which
specialist did it, which model and why that model was chosen, what it was
given, what came back, how risky it was, and whether anything left this
computer and where to.

Open "What I did" to read the record. Filter it to the last day, week or
month, to actions that change something, or to what left this computer.
Deleting a conversation removes its words from the record; the fact that an
action happened stays. The record is kept for six months.

## Control
The Control page lists every capability I have. For each one it says whether
using it can send anything off this computer and what, how much I ask before
using it, and a switch that takes it away completely. What may leave the
computer at all is the separate Privacy setting.
