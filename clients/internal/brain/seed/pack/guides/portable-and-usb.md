# Portable copy, USB stick and Remote

## Two ways to run it
- Installed (Linux .deb, Windows installer): menu entry, the brain in your
  account.
- Portable (Windows zip, or any copy with a file named PORTABLE beside the
  program): nothing is installed, the brain lives in PN-SCRIPTS-ASSISTANT-DATA
  beside the program, and the computer it runs on does not remember it.

## Taking the brain with you
Copy the portable folder to a USB stick and run it on any computer. The
knowledge folder, the playbooks and the memory go with it. What it keeps about
you is encrypted; on a new computer it may ask for your recovery key once —
keep that key somewhere safe, away from the stick.

## Remote
A brain opened through Remote runs on the computer that holds it; its
knowledge and playbooks are read there, so they are the same wherever you
connect from.
