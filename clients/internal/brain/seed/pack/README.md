# Knowledge that came with PN Scripts Assistant

This folder is the brain's own knowledge. It travels with the brain — on a USB
stick, through Remote, to another computer — and everything in it is learned.

The files under `guides/` were written into it by the program. Change them
freely: a file you have edited is never overwritten by an update, and new
guides are added beside yours. Put your own documents, notes and rules anywhere
in this folder and they are learned the same way.
