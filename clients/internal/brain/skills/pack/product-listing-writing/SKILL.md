# Product listing writing

A listing answers the buyer's questions before they ask them and makes the right buyer click "Add to cart". Accurate beats hyped: wrong details cause returns.

## Steps
1. **Gather facts.** Ask for: product name, what it is for, who buys it, materials, dimensions, weight, variants, what is in the box, care, origin, certifications, price, delivery times, and the marketplace. Use a spec sheet if available; never invent specs.
2. **Find the buyer's words.** How would a buyer search for it? Combine the product type, key attribute and use: "Linen apron with pockets for baking".
3. **Write the title** following the marketplace's rules and length limit: product type + key attributes (material, size, colour, quantity) + main use. No ALL CAPS, no promotional words if the marketplace forbids them.
4. **Write 3-5 key benefits** as short bullets: benefit first, then the feature that proves it.
5. **Write the description:** a 1-2 sentence opening for the ideal buyer, then details, use cases, sizing guidance, care, what is not included.
6. **Add structured specs:** a table with dimensions (in the units buyers expect, both if international), weight, material, compatibility, warranty.
7. **List images needed:** main image on a clean background, scale/in-use shot, detail close-up, all variants, packaging, size chart. Add alt text.
8. **Check compliance:** required labels for the category (e.g. textiles composition, electrical safety marks, age warnings for toys), no health or eco claims without proof, no brand names you are not allowed to use.

## Template
```
Title: [Product type] - [key attribute], [material], [size/qty] for [use]
Bullets:
- [Benefit] - [feature that proves it]
Description: [Who it is for + main result]. [Details]. [Sizing]. [Care].
Specs: Dimensions | Weight | Material | In the box | Warranty
Search terms: [synonyms, uses, gift occasions - not in the title twice]
```

## Example
Weak: "Beautiful apron!!! Best quality."
Better: "Linen Apron with 2 Pockets - Adjustable Neck Strap, Stonewashed, 70 x 85 cm. Soft from day one, machine-washable at 40 C, fits sizes S-XL."

## Checklist
- Title readable by a human, not only by search.
- Every claim in the bullets is supported by the specs.
- Sizes, compatibility and what is not included are stated.
- Images match the variants and the text exactly.

## Pitfalls
- Copying the manufacturer's text word for word duplicates many other listings.
- Keyword stuffing in titles can get a listing suppressed.
- Leaving out sizes, compatibility or what is not included leads to returns and bad reviews.
- Marketplace rules change; check the current title, image and category requirements.

## Output
The title, bullets, description, specs table, search terms, image shot list with alt text, and a list of facts still missing from the user.
