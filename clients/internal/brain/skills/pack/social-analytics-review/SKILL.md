# Social analytics review

Numbers only matter in relation to a goal. Compare like with like, look for patterns across several posts, and end with decisions.

## Steps
1. **Set the frame.** Ask for the goal (awareness, traffic, leads, sales, community), the period, the comparison period, and the data: export file, screenshots or numbers per post.
2. **Clean the data.** One row per post with date, platform, format, topic/pillar, reach or impressions, likes, comments, shares, saves, link clicks, follows, conversions if tracked. Note missing fields instead of guessing.
3. **Compute the core metrics:**
   - Engagement rate by reach = (likes + comments + shares + saves) / reach x 100
   - Click-through rate = link clicks / impressions x 100
   - Follower growth = (end - start) / start x 100
   - Conversion rate = conversions / clicks x 100 (needs UTM tags or platform tracking)
4. **Compare.** This period vs the previous one and vs the account's own median, not vs other brands' published numbers.
5. **Find patterns** with at least 3-5 posts behind each: which pillar, format, hook type, posting time and length do best; which underperform.
6. **Explain changes carefully.** A drop can come from fewer posts, a format shift, seasonality, a platform change or a tracking change. Say which explanations the data supports and which are guesses.
7. **Decide.** Do more of / do less of / test next, each with a measurable target.

## Example
Instagram, September vs August: reach -18%, engagement rate 4.1% -> 5.3%, posts 16 -> 10.
Reading: fewer posts explain most of the reach drop; per-post quality improved. Carousels with tips had double the saves of single photos.
Decision: keep 3 carousels a week, return to 12-14 posts a month, test reels on Tuesdays for 4 weeks.

## Report template
```
Period: [dates] vs [previous dates]     Goal: [goal]
Summary: [3-5 lines]
| Metric | This period | Previous | Change |
| Reach | ... | ... | ...% |
| Engagement rate | ... | ... | ... pp |
| Link clicks | ... | ... | ...% |
| Conversions | ... | ... | ...% |
Top posts: [title - metric - why it worked]
Weak posts: [title - metric - likely reason]
Actions: [do more / do less / test - target]
```

## Pitfalls
- Vanity metrics (likes, followers) without a link to the goal.
- Concluding from one viral post.
- Mixing impressions and reach, or comparing different time windows.
- Platforms change metric definitions and export columns; check the current definition in the platform's help pages.

## Output
A short summary (3-5 lines), a table of key metrics with change vs the previous period, the top and bottom 3 posts with reasons, and 3-5 concrete actions with targets for the next period.
