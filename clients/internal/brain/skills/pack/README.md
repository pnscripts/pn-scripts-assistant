# The built-in skill pack

Each folder here is one skill shipped inside the program: `SKILL.md` (name and
description in its front matter, the instructions in its body), optionally
`SKILL.bg.md` (the same in Bulgarian) and `references/` or `scripts/` beside
them. On start they are written into the brain's knowledge folder
(`knowledge/pack-skills/`), so the full skill, with its files, can be read
like any other; the Skills page shows them with a "built-in" badge.

Nothing here may be specific to one person or company: these ship to every
user. A test checks it.
