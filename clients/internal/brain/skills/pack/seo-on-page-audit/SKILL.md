# On-page SEO audit

Audit one page against the query it should rank for. Fix what helps searchers first; never recommend tricks that search engines penalise.

## Steps
1. **Pin the target.** Ask for the URL or HTML, the main search phrase, the audience and the country/language. Without a target phrase, propose 2-3 from the content and confirm.
2. **Check search intent.** Look at what kind of pages already rank for the phrase (guide, product, comparison, local listing). If the page type does not match, say so first; no tag tweak fixes a wrong format.
3. **Run the checklist** (below) and mark each item pass / fix / not applicable.
4. **Check technical basics you can see:** `noindex` or `nofollow` in meta robots, canonical pointing to itself (or the right master page), status 200, `lang` attribute, mobile viewport, obvious heavy images or scripts. Suggest measuring speed with the search engine's own tools (e.g. PageSpeed Insights, Search Console) rather than guessing numbers.
5. **Prioritise.** High = blocks indexing or misses intent; Medium = title, H1, thin content, missing internal links; Low = polish.
6. **Write the fixes**, not just the problems: give the new title, meta description and H1 text ready to paste.

## Checklist
- Title: unique, main phrase near the start, about 50-60 characters, brand at the end.
- Meta description: about 140-160 characters, states the benefit, invites the click; it does not affect ranking directly but affects clicks.
- One H1 that matches the topic; H2/H3 in logical order, no headings used only for styling.
- Main phrase and natural variants in the first paragraph, headings and image alt text, without stuffing.
- Content answers the question fully, shows first-hand experience, author or company, date if time-sensitive.
- URL short, readable, hyphenated, lowercase.
- 3+ relevant internal links in, and descriptive anchor text out (not "click here").
- Images: compressed, sized, descriptive file names and alt text, lazy-loaded below the fold.
- Structured data that fits (Article, Product, FAQ, LocalBusiness, BreadcrumbList) and validates.
- Open Graph title, description and image for sharing.

## Example
Target: "handmade leather wallet". Current title: `Home | Shop`.
- Fix (High): title -> `Handmade Leather Wallets - Slim, Full-Grain | BrandName` (56 chars).
- Fix (Medium): H1 "Welcome" -> "Handmade Leather Wallets".
- Fix (Medium): add a 150-word intro on materials, sizes and care; link to the care guide.

## Questions to ask
- Which page should rank for this phrase if several pages cover it?
- Is the page new, or did it lose rankings after a change (redesign, URL change, content cut)?

## Pitfalls
- Keyword stuffing, hidden text and doorway pages hurt rankings.
- Several pages aiming at the same phrase compete with each other; merge or differentiate them.
- Do not promise rankings or traffic numbers; results depend on competition and time.
- Ranking factors and tool menus change; tell the user to check the search engine's current official guidance.

## Output
A short summary (target phrase, intent match yes/no), a prioritised table of issues with the exact fix, and ready-to-paste title, meta description and H1.
