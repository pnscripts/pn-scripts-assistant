# Device security basics

Bring the device to a solid baseline using built-in features first. Settings move between versions: describe what to look for and tell the user to check the vendor's official help if a menu differs. Never ask for passwords.

## Steps
1. **Identify the device:** type, operating system and version, who uses it, whether it is still supported with security updates (check the vendor's official support page). An unsupported system is the biggest risk; plan a replacement or a supported system.
2. **Updates:** turn on automatic updates for the system, browser and apps; install pending ones now; restart.
3. **Lock:** screen lock with a PIN of 6+ digits or a strong password, biometrics optional; auto-lock after a short idle time; lock-screen notifications hidden for sensitive apps.
4. **Encryption:** confirm full-disk or device encryption is on (most modern phones do this when a lock is set; laptops may need it enabled). Store the recovery key safely, not on the same device.
5. **Backups:** automatic backups of photos and documents, ideally the 3-2-1 idea: 3 copies, 2 different media, 1 off-site or in the cloud. Test a restore of one file.
6. **Malware protection:** keep the built-in protection on; install apps only from official stores or vendor sites; remove apps and browser extensions not used; do not disable security warnings.
7. **Accounts:** use a standard (non-admin) account for daily use on computers; separate accounts for family members; see `password-and-2fa-hygiene`.
8. **Network:** change the router's default admin password, use WPA2 or WPA3, update router firmware, turn off WPS and remote admin if unused, put smart devices on a guest network if possible. On public Wi-Fi, avoid sensitive tasks or use the mobile connection.
9. **Lost device:** turn on the official find-my-device feature and remote wipe; note the device's serial number.
10. **Before selling or giving away:** back up, sign out of all accounts, remove the device from the account, then factory reset.

## Signs of infection and what to do
Signs: new unknown apps or extensions, pop-ups, browser home page changed, battery or data draining fast, accounts sending messages you did not write, security turned off by itself.
1. Disconnect from the internet.
2. Run a full scan with the built-in protection; remove what it finds; remove unknown apps and extensions.
3. From a different, clean device, change passwords for email and banking and sign out other sessions.
4. If ransom notes, banking fraud or persistent problems appear, get professional help; for fraud contact the bank at its official number.

## Checklist
- [ ] Supported OS, updates automatic
- [ ] Strong screen lock, auto-lock on
- [ ] Encryption on, recovery key stored safely
- [ ] Automatic backup, restore tested
- [ ] Only needed apps and extensions
- [ ] Router secured, firmware updated
- [ ] Find-my-device on

## Pitfalls
- Installing "cleaner" or "booster" apps from ads; many are adware.
- Calling a tech-support number from a pop-up (a common scam).
- Keeping the only backup on a drive always plugged into the same computer.
- Running several antivirus products at once.

## Output
Hand back: the device's current status against the checklist, the ordered steps to fix gaps, any urgent issue first (unsupported system, infection signs), and items to confirm on the vendor's official help pages.
