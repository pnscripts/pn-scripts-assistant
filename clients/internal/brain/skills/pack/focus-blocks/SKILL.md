# Focus blocks

Protected time for one demanding task. The block works only if it has a clear target, a defended start and a defined end.

## Steps
1. **Choose one task** with a concrete finish line for the block: "draft sections 1-2 of the report", not "work on report".
2. **Pick the length.** Start with what the user can actually hold: 25 minutes (Pomodoro, 5-minute break), 50/10, or 90 minutes for experienced deep work. Build up gradually.
3. **Pick the time.** Put blocks in the user's peak energy hours (often the morning for many people; ask). Avoid stacking them right after long meetings.
4. **Book it in the calendar** as a real appointment with a clear title; make it visible to colleagues if possible.
5. **Prepare in 5 minutes before:** open only the needed files, close other tabs and apps, water, notes, write the first step on paper.
6. **Block interruptions:**
   - phone in another room or face down on do-not-disturb,
   - email and chat closed; status set to "focusing until 11:00",
   - a "parking" note for thoughts that pop up, to handle later.
7. **During the block:** if stuck, write the smallest next step; do not switch tasks. If an interruption is truly urgent, note where you stopped before leaving.
8. **Break properly:** stand, move, look into the distance, no feeds.
9. **Close the block:** write where to restart next time, then review what worked.

## Sample day plan
```
08:30-08:40  plan the day, open files
08:40-10:10  Focus block 1: finish proposal draft
10:10-10:30  break, messages
10:30-12:00  meetings / shallow work
13:30-14:20  Focus block 2: data analysis section
14:20-14:30  break
14:30-16:30  email, calls, admin (batched)
```

## Message for colleagues
"I am in focus time until 11:00 for the client proposal. For anything urgent, call me; otherwise I will reply after 11."

## Pitfalls
- Choosing vague or too-big tasks; the block ends with nothing finished.
- Checking messages "just once" in the middle; recovery takes many minutes.
- Scheduling five blocks a day; two or three real ones are a good day for most people.
- Feeling guilty when a block fails; adjust the length or time and try again.

## Output
A plan with the chosen task and finish line, block length and times in the calendar, an interruption checklist tailored to the user, and a short message for colleagues if needed.
