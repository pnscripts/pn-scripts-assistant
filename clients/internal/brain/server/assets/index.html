Models in use

Both models cannot be held in memory at once on this machine, so every switch between them reloads one — which costs more than choosing the smaller one saves. Ollama is set to keep two models, and the memory used for remembering takes one of those. Raising it to three fixes it; there is room.


                    

                

                

                    
Mailbox

                    
Fill these in yourself and the brain can read and write
                        your mail. Use an app password, not your account
                        password — every provider worth using issues them, they can be
                        revoked on their own, and they cannot be used to take the account
                        over. It is kept in the settings file beside the brain and sent
                        only to your own mail server.

                        and closing it changes nothing at all.
