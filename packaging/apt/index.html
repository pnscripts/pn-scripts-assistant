PN Scripts Assistant for Ubuntu

This is the apt repository of PN Scripts Assistant, a private assistant that runs on your own computer. Add it once and every new version arrives through Software Updater, like any other update.

Install

sudo wget -qO /etc/apt/sources.list.d/pn-scripts-assistant.sources https://pnscripts.github.io/pn-scripts-assistant/apt/pn-scripts-assistant.sources
sudo apt update && sudo apt install pn-scripts-assistant

Installing the .deb from the releases page adds this repository too (from version 0.12.0).

Update

Nothing to do: Software Updater shows new versions. Or: sudo apt update && sudo apt upgrade

Signing key: pn-scripts-assistant-archive-keyring.asc (fingerprint E7D0 F5EF B64A E571 F126 AAEE 03EC 93CE C2C8 52F1).

Ubuntu 24.04 and newer, 64-bit PCs. Made by PN Scripts.
